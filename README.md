# NoPressure

iOS-first dating app designed to increase real-world meetups, not endless app engagement.

## Current Product Shape (MVP)
- No swiping, no liking, no prompt roulette; users are directly sent matches
- Max 3 active matches per user
- Every match expires after 7 days
- Local-only matching for realistic in-person dates
- 18+ only

## Tech Stack
- iOS app: Swift + SwiftUI
- Backend: Supabase (PostgreSQL, Auth, Storage, Realtime)
- Architecture style: pragmatic MVVM, fast iteration, readable code
